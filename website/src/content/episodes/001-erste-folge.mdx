## Show Notes

In der ersten Folge stellen sich Michael und Levin vor. Beide sind Fullstack-Entwickler, die seit rund einem Jahr intensiv mit AI-Tools arbeiten. Sie sprechen über ihre Setups, Subscriptions, Workflows mit Claude Code und wie sich die Rolle als Entwickler gerade fundamental verändert.

### Themen

- **Vorstellung**: Wer sind Michael und Levin, woher kennen sie sich (Uplink), warum ein Podcast
- **Setup & Subscriptions**: Claude Max (90€/180€), ChatGPT Plus, API-Kosten vs. Abo, Token-Tracking mit ccusage
- **Workflows**: Skills, Boilerplate-Repos, Feature-Branch-Entwicklung mit AI, Conventional Commits
- **Michaels Stack**: React Native + Convex (Backend-as-a-Service), Maestro für Mobile E2E Testing
- **Levins Stack**: Astro, Dev-Container, Zellij, Claude Code CLI, Git Worktrees
- **Claude Code Web & Mobile**: Projekte vom Handy aus steuern, Speech-to-Text mit Dictate-App
- **Claude Code in GitHub**: Issues an Claude assignen, GitHub Actions Integration
- **Entire**: Neue Company vom Ex-GitHub-CEO für Agenten-Transparenz in Git (60M Seed Funding)
